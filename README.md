# Portafolio - Juan Villegas

Más que una simple galería de proyectos, este portafolio es una demostración de mi estilo como Desarrollador Frontend y Creativo.

Diseñado bajo el concepto "Ethereal Flow", busqué crear una experiencia inmersiva que combine un modo oscuro profundo, tipografía cinética y transiciones fluidas que se sientan naturales.

## 🛠 Con qué está hecho

No es solo código, es la selección de herramientas que disfruto usar:

-   **Core**: Next.js 16 (App Router) - La base sólida.
-   **Estilos**: Tailwind CSS v4 - Para iterar rápido y mantenerlo limpio.
-   **Movimiento**: Framer Motion - La "magia" detrás de cada interacción.
-   **Fuentes**: Syne (Headers) & Manrope (Cuerpo) - El carácter visual.

## ✨ Lo destacado

Le puse mucho cariño a los detalles, especialmente a:

-   **Navegación Flotante**: Un menú estilo "dock" que responde magnéticamente al cursor.
-   **Tipografía Cinética**: Títulos que cobran vida mientras haces scroll en el Hero.
-   **Bilingüe Real**: Contexto de React para cambiar entre Español e Inglés instantáneamente.
-   **Performance**: Imágenes optimizadas y SEO cuidado para que no solo se vea bien, sino que funcione bien.
